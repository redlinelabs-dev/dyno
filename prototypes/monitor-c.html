Results

Scheduled tests

Each scheduled test runs from this dyno to a far end: another dyno that you run somewhere else, such as a VPS or a relative's house. It tests the line between the two and keeps every result in History. Changes apply at once, with no restart.

    Alerts

    dyno sends one message when scheduled tests stay slow, and one when they recover. A single slow result does nothing. Changes apply at once.
