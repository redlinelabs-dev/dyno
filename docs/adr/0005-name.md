# ADR-0005: The product is called dyno

Status: accepted 2026-10-30 by the owner (was decisions-pending #2): "dyno
sounds like a great name for this".

## Context

A dynamometer gives an honest power reading under load, which is what dyno does
for a network link and fits Redline Labs' automotive language.

## Decision

The product, binary, container image and repo are `dyno`.

## Consequences

- Before the repo goes public (M4), check for conflicts that would force a
  rename: a trademark search in software and networking classes, and the names
  `dyno` on GHCR, Docker Hub and the iOS App Store. "Dyno" is also Heroku's
  word for a container and a popular Discord bot's name; neither is a speed
  test, so a qualifier such as "Redline Dyno" on stores is the likely fix if one
  is needed, not a new name.
